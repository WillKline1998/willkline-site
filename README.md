# willkline.com

Will Kline's personal site: music, CV, media, writing, a lab for music-software experiments, and an Inspiration Wall. Includes a **demo mode** toggle that turns the site into a showcase of creative UI.

## Run locally
```bash
npm install          # also generates the Prisma client
npm run db:migrate   # create/update the local SQLite database
npm run dev          # http://localhost:3000
```
